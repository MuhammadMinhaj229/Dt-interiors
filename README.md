**DT Interiors** is a high-end digital portfolio and client inquiry platform engineered for architectural studios, residential decorators, and luxury interior contractors. Powered by Alif Growth Media.

---

## ⚡ Highlights

- **Visual Project Gallery:** High-resolution presentation of completed modular kitchens, living spaces, and commercial renovations.
- **Inquiry & Consultation Pipeline:** Structured customer intake capturing room dimensions, design preferences, and estimated budget.
- **Ultra-Fast Bun Runtime:** Built with modern TypeScript and Bun for lightning-fast server responses and minimal resource footprint.
- **Direct WhatsApp Design Consultation:** Instant click-to-chat pre-filled with the client's selected portfolio project.

## 💻 Local Setup & Deployment

```bash
# 1. Clone repository
git clone https://github.com/MuhammadMinhaj229/Dt-interiors.git
cd Dt-interiors

# 2. Install dependencies with Bun
bun install

# 3. Start local development
bun run dev
```

### Deploy to Vercel
1. Import repository into Vercel.
2. Build command: `bun run build` (or `npm run build`).
3. Deploy to edge.
