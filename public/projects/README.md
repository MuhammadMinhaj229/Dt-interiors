# DT Interiors - Project Image Folder

Place your completed project pictures directly inside this folder.
The website is pre-configured to load them with fallbacks.

## Filename mapping:
1. **bespoke-wardrobe.jpg** - Dual-Tone sliding wardrobe picture
2. **teak-glass-closet.jpg** - Teak wood glass wardrobe picture
3. **sacred-lotus-pooja-partition.jpg** - Lotus pooja partition screen picture
4. **geometric-organic-ceiling.jpg** - LED profile false ceiling picture

Simply drag and drop your files here via the file explorer and make sure they are named exactly as shown above in lowercase.
